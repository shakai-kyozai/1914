# 総力戦1914

中学校社会科（歴史）の授業で使う、第一次世界大戦のゲーム教材です。生徒はドイツ帝国の戦争指導部になり、人・砲弾・食料を前線と国内に配分しながら、1914年秋から1918年秋までを半年ごとに進めます。1916年春には、ヴェルダンの戦闘（リアルタイム）が入ります。ゲームのあとに映画『西部戦線異状なし』を見る授業を想定しています。

## 遊び方

`index.html` をブラウザで開きます（同じフォルダの `art` `music` `media` と、`*_glb.js` などのファイルも一緒に置いてください）。最初の画面の右上の「English」で英語版に切りかわります。アドレスの最後に `#en` を付けて開いても英語になります。

## フォルダ

- `index.html` … ゲーム本体（1つにまとめたもの）
- `art/` … 政策とできごとの絵（政策の id、決断の番号 ev0〜ev7 の名前）
- `music/` `media/` … 音楽と、最初の画面の動画
- `ally_glb.js` `soldier_tw_glb.js` `tanks_glb.js` など … 兵士・戦車などの立体モデル

## 出典・クレジット

- 地図の海岸線と国境：Natural Earth（パブリックドメイン）
- ヴェルダン周辺の標高：フランス国立地理森林情報院（IGN）RGE ALTI
- ヴェルダンの塹壕線：Henry Bidou «La Bataille de Verdun»（1916年）に出てくる地名をもとにした目安
- 戦車のモデル（CC BY）と、兵士の動きのデータ（CMU Graphics Lab Motion Capture Database）のクレジットは、ゲームの中の「クレジット」に表示しています
- 効果音は、ゲームに組みこんだ形で使っています。音のデータだけを取り出して配ることはできません
